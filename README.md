# Another Minimal Template for Digital Scholarly Editions (Under development)

Inspired by the previous project [Ed. a jekyll theme for minimal edition](https://minicomp.github.io/ed/), this repository will provide a lightweight, customizable **Jekyll template** for creating and publishing a minimal digital scholarly edition as an static websites. It is intended for teaching, prototyping, and developing sustainable digital editions using minimal computing principles, and it is still under development. 

## 🌐 Live Preview

To view a demo (if hosted via GitHub Pages), visit:  
`https://susannalles.github.io/DSE_template/`

## 📁 Structure

- `index.md` – Homepage with a brief introduction to the edition
- `edition/` – Folder where HTML resulting/ transformed encoded texts reside
- `_layouts/` – HTML templates for rendering content pages
- `_includes/` – Reusable site components (navigation, head, footer)
- `assets/` – CSS (`style.css`) and JavaScript
- `_config.yml` – Site metadata and configuration
- `XML/` – XML files.
- `XSLT/`- XSLT files.
- `images/` - folder containing all images for the site. 

## 👌🏽 Features

- Clean and responsive layout for Homepage.
- Default pages with sidebar navigation.
- ...

## 🚀 How to Use

1. **Fork or clone** this repository.
2. Replace or edit the contents of the `edition/` folder.
3. Customize the homepage and layout as needed.
4. Commit your changes and enable GitHub Pages from the `Settings` > `Pages` section.
5. View your live site at `https://your_username.github.io/DSE_template/`
